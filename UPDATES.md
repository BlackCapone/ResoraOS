# Как работают обновления Resora OS

Вкладка «Обновления ПО» в настройках — это интерфейс к `apt`, обычному менеджеру пакетов Ubuntu.

## Что обновляется
1. **Система** (ядро, библиотеки, браузер Epiphany, исправления безопасности) — из репозиториев Ubuntu.
2. **Сама Resora** (интерфейс, мост к системе, скрипт сессии) — пакет `resora-shell` из репозитория Resora.
   Версия — дата сборки (`1.0.ГГГГММДДЧЧММ`), поэтому каждая новая сборка видна apt как обновление.

## Что нужно для обновлений Resora
- Веб-сервер с репозиторием. Проще всего — GitHub Pages (бесплатно): workflow `publish-apt.yml` сам собирает пакет,
  делает репозиторий и подписывает его.
- Ключ подписи (GPG): без подписи apt откажется доверять репозиторию.
  ```
  gpg --quick-generate-key "Resora <you@example.com>" rsa4096 sign never
  gpg --armor --export-secret-keys <ID>  # → секрет APT_GPG_PRIVATE_KEY в Settings → Secrets → Actions
  gpg --armor --export <ID> > packaging/resora.gpg   # открытый ключ — в репозиторий, его вшивает сборка ISO
  ```
- Адрес репозитория для образа: в Settings → Variables → Actions задайте `RESORA_APT_URL`
  (например `https://ВАШЛОГИН.github.io/ИМЯ_РЕПО`). Сборка ISO пропишет его в `/etc/apt/sources.list.d/resora.sources`.

## Как выходит обновление
Изменили интерфейс → `git push` в `main` → workflow `publish-apt` собирает новый `resora-shell` → в течение суток
(или по кнопке «Проверить») установленные системы видят обновление → «Обновить» → интерфейс заменяется на месте.

## Автоматически
Переключатель «Автоматические обновления» включает таймеры `apt-daily` и `unattended-upgrades`: раз в сутки система сама
проверяет и ставит обновления безопасности Ubuntu и новые версии Resora (`52resora-unattended`). Перезагрузка сама не выполняется:
интерфейс показывает «Нужна перезагрузка».

## Ограничения
- В **живой сессии** (запуск с флешки без установки) всё лежит в оперативной памяти: обновления пропадут после выключения.
  Чтобы они сохранялись, нужна установка на диск.
- Откат: старые версии остаются в кэше apt (`apt install resora-shell=<версия>`); автоматического отката пока нет.
