# Resora OS — загрузочный ISO

Живой образ (Ubuntu 24.04 + `live-boot`): грузится сразу в интерфейс Resora. Интерфейс — HTML-версия из папки `ui/`,
запускается на экране во весь размер через `cage` (Wayland) и WebKitGTK. Мост `shell.py` + `resora_bridge.py` даёт
интерфейсу настоящие функции системы.

## Что работает по-настоящему
- Питание (выключение, перезагрузка, сон) с экрана входа — двойное нажатие для подтверждения.
- Wi-Fi: поиск сетей и подключение в мастере настройки, включение/выключение радио в Пункте управления, имя сети в меню.
- Громкость и яркость экрана (Пункт управления). Батарея в строке меню (если есть).
- Finder показывает настоящие папки (домашняя папка, «Компьютер»), открывает текстовые файлы и картинки.
- Значок Safari запускает настоящий браузер Epiphany (WebKit), значок «Терминал» — терминал foot.

## Что остаётся только в интерфейсе (пока без начинки)
Почта, Сообщения, FaceTime, Карты, Фото, Календарь, Напоминания, TV, Музыка, App Store; плитки Bluetooth, AirDrop, Фокус,
Stage Manager. **Установки на диск нет** — это живая сессия, после выключения ничего не сохраняется.
Chromium в образ не входит (в Ubuntu он только snap-пакетом, а в образ его не положить) — вместо него Epiphany.

## Обновления
Вкладка «Обновления ПО» работает через apt: система, браузер и сама Resora. Подробности и настройка репозитория — в `UPDATES.md`.

## Как запустить
1. Запишите `resora-os.iso` на флешку: Rufus (режим **DD-образ**) или balenaEtcher.
2. **Отключите Secure Boot** в BIOS/UEFI (загрузчик не подписан), загрузитесь с флешки.
3. Пункты меню GRUB: обычный; «безопасная графика» (всё на процессоре — если экран пустой); «ускорение GPU» (экспериментально).

## Как собрать самому
Нужна Ubuntu/Debian с root и ~8 ГБ места: `sudo ./build-iso.sh` (переменные — в начале скрипта). Результат: `out/resora-os.iso`.
Без Linux: залейте папку в репозиторий GitHub и запустите Actions → build-iso → Run workflow (укажите тег, например `v1.0.0`): ISO соберётся в облаке и появится в Releases.
Свой интерфейс: положите папку с `index.html` в `ui/` (исходники интерфейса — в `tools-web/`, пересборка `python3 tools-web/apply_v16.py`).
Тесты моста: `python3 -m unittest discover -s tests`.
