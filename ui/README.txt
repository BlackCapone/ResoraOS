Resora Desktop Preview — v15 functional fixes

Запуск
1. Распакуйте архив в обычную папку.
2. Запустите Start-Resora.bat.
3. Рекомендуется Microsoft Edge или Google Chrome.

Что исправлено в v15
- Исправлена ошибка старта JavaScript: applyTheme обращалась к отсутствующему #darkSwitch и останавливала выполнение оставшегося кода.
- Восстановлена работа мастера первого запуска и переходов между разделами системных настроек.
- Исправлены интерактивность дока и вертикальное выравнивание иконок.
- Иконки приложений, у которых пока нет собственного интерфейса, открывают отдельное окно с пояснением вместо ошибки отсутствующей функции.
- Панель управления перестроена по референсу macOS 27: полупрозрачные голубые стеклянные блоки, подключение, медиаплитка, быстрые действия и ползунки.
- Добавлен резервный режим хранения настроек в памяти, если localStorage недоступен.
- Добавлена обработка нажатий пунктов верхнего меню.

Важно
Это HTML/CSS/JavaScript-прототип оболочки, а не отдельная операционная система. Ползунки яркости и звука и некоторые переключатели меняют только состояние интерфейса и не управляют настоящими системными устройствами Windows. Приложения, помеченные как ещё не подключённые, показывают окно-заглушку.

Превью PNG, оставшиеся в архиве, относятся к более ранним версиям и не являются скриншотами нового интерфейса v15.


=== v16 ===
Что изменено:
- Мастер настройки переделан: по центру, без боковой панели, живое приветствие на разных языках, прогресс точками.
  Язык (русский/английский) действительно переключает мастер и экран входа. Имя пользователя подставляется из имени
  автоматически, есть показ пароля и индикатор надёжности. Убраны служебные пояснения про «прототип» и «Windows».
- Док: настоящее стекло (размытие, блик по краю, внутреннее свечение), плавное увеличение иконок под курсором.
- Пункт управления: макет macOS 27 — блок Wi-Fi / Bluetooth / AirDrop, Фокус, Stage Manager, Повтор экрана,
  ползунки «Дисплей» и «Звук», карточка «Музыка». Светлая и тёмная темы.
- Иконки: заново нарисованы Launchpad, Safari, Сообщения, Почта, Карты, Напоминания, Терминал, Калькулятор, Погода,
  TV, Музыка, App Store, Системные настройки, Загрузки, Корзина. Finder, Фото, Заметки, FaceTime, Календарь не менялись.
- Spotlight показывает настоящие иконки приложений (раньше часть была пустой).
- Фон (assets/wallpaper.svg) не менялся.

Ограничения (это браузерный прототип):
- Список Wi-Fi в мастере имитирован: браузер не может сканировать сети; подойдёт любой непустой пароль.
- Язык переключает только мастер и экран входа, остальные приложения пока на русском.
- Плеер в пункте управления без звука (кнопки только показывают, что он не подключён).

Как пересобрать index.html из исходников: python3 tools/apply_v16.py (оригинал v15 лежит в tools/index.v15.html,
правки — в tools/v16/, иконки генерирует tools/gen_icons.py).

v16.1: материал «стекло» переделан (прозрачная заливка, тонкие блики по кромке, свечение у края, без градиентной
«пластиковой» заливки) для дока, панели управления и карточки мастера. Раскладка панели управления будет уточнена
по эталонному скриншоту macOS 27.

v16.2: Пункт управления переделан под macOS 26/27 (раньше был в раскладке macOS 13): сетка из 4 колонок, каждый элемент —
отдельная стеклянная плитка: Wi-Fi, Bluetooth, AirDrop и Фокус (средние), ползунки «Дисплей» и «Звук» и «Музыка» (на всю
ширину), ряд малых плиток (тёмное оформление — работает по-настоящему, яркость клавиатуры, повтор экрана, Stage Manager),
внизу «Изменить элементы…». Редактирование плиток пока не реализовано.
